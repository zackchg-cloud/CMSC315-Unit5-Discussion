I also learned that dictionaries provide efficient lookup performance because Python uses hashing to quickly locate data associated with a key. In most cases, these operations occur in constant time, which makes hash tables very useful when working with large amounts of data.

One challenge I encountered was understanding what happens when a key does not exist in the dictionary. I overcame this by using the get() and pop() methods with default values, which allowed the program to handle missing keys safely without generating errors. Testing edge cases helped me better understand how dictionary operations behave under different conditions.

Hash tables work by applying a hash function to a key and using the resulting hash value to determine where data is stored. A collision occurs when two keys produce locations that overlap within the hash table. Python handles collisions internally, allowing dictionaries to continue functioning correctly. Even though collisions can slightly impact performance, hash tables remain highly efficient and are commonly used in applications that require fast data retrieval.
