While completing this assignment, I learned how linear search and binary search work and how algorithm efficiency affects performance. I practiced implementing both search algorithms in Python and testing them with different dataset sizes. I also learned how time complexity impacts the number of operations required to find a value.

One challenge I encountered was understanding why binary search requires a sorted dataset. At first, both algorithms seemed similar because they ultimately locate the target value. After testing the algorithms and reviewing the search process, I understood that binary search depends on the data being sorted so it can eliminate half of the remaining search space during each iteration.

Linear search is most useful when data is unsorted or when working with smaller datasets because it can search any collection without special preparation. The tradeoff is that it may need to examine every element, giving it a time complexity of O(n). Binary search is better for large sorted datasets because it reduces the search space by half each step, resulting in O(log n) performance. The tradeoff is that the data must already be sorted before binary search can be used effectively.
