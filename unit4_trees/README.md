While completing this assignment, I learned how Binary Search Trees (BSTs) use a hierarchical structure to organize data efficiently. I implemented recursive insertion, searching, and in-order traversal methods, which helped me better understand how recursion works when navigating through a tree. I also learned how the BST property keeps smaller values in the left subtree and larger values in the right subtree, making data easier to locate.

One challenge I encountered was understanding how the recursive functions moved through the tree during insertion and search operations. At first, it was difficult to visualize how the program determined whether to move left or right. I overcame this challenge by tracing the code step by step and examining the output after each operation. This helped me understand how the tree structure was built and maintained.

Binary Search Trees improve efficiency because each comparison narrows the search space by directing the search to either the left or right subtree. This is generally faster than a linear search, which may need to examine every element. However, BSTs can become inefficient if values are inserted in sorted order because the tree can become unbalanced and resemble a linked list. When properly balanced, BSTs provide efficient searching, insertion, and traversal operations.
